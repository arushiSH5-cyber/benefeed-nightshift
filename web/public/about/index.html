HOW THE AUTOMATION WORKS

No API, no backdoor: it uses the website like you do

1
A real phone opens the site
open_url("…/practice")
2
It reads the screen (labels, fields, buttons) and Claude picks ONE action
fill("How many people live with you?", "2")
3
PhoneUse taps & types, then it looks again to verify
tap("Next") → not final → allowed
🔒
A final button? The guard blocks it and LangGraph pauses
tap("Submit") → FINAL → HardStop → interrupt()
✓
You hold to approve, and only then: Submit → Confirm
approval #1 → tap("Submit") → tap("Confirm")
🧩
Real portals: you log in yourself; CAPTCHAs, codes and ID uploads go back to you
